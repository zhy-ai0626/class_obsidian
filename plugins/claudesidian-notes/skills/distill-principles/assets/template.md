# `_principles.md` 文件结构模板

严格按此结构生成。文件长度 200-400 行（超出说明没"读薄"，低于说明缺内容）。

## Frontmatter

```yaml
---
type: principles
course: <CODE>
title: "<CODE> <课程英文名>：原理与推导"
date: <学期>
---
```

## 符号表编制规则

- **每个符号给中英双语**（用户可能要看英文教材 / 考英文卷）
- **多义符号**列出每个含义 + 节号（如 "$a$ 化学计量 §1.3 / 催化剂活性 §9.2"）
- **易混符号**加提醒（如 "$Da$（**不要跟 $D_a$ 混**）"）

## 公式编号约定

- (X.Y) **连续编号到底** — 不能跳号
- X = 章节号；Y = 该章节内公式序号
- 跨节引用直接写 "由 (2.5) 代入..."（不带节号前缀）
- 末尾 §N+1 公式索引按编号查节（不按主题，主题已在 § 标题里）
