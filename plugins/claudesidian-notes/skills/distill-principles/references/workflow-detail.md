# Workflow 详细做法

主流程在 SKILL.md。这份给每个 Step 的具体操作 + 判断标准。

---

## Step 1.5: 全 lecture 强制扫公式

**Anti-CME222-bug 关键步骤**。

CME222 第一次跑 distill 时只看 L12 revision，结果 17 个 tutorial 用到的公式没收（球/圆柱坐标闭式、Solution-Diffusion、Wilke 调和完整公式、Scheibel、Leffler-Cullinan、Tyn-Calus、Nernst、Hindered diffusion、混合扩散含 α、准稳态显式时间公式、单向扩散指数浓度分布、温度外推、Brokaw 修正…）。

**做法**：

1. `Grep "\\$\\$"` 每个 L##.md 找所有公式块
2. 列出 `公式名 / 出处 L## §X / LaTeX` 大清单
3. Step 2-3 在大清单基础上选 / 编号（不是凭印象）

⚠️ **不要只读 lecture 的 revision / 速查卡节** — 那只覆盖老师重点讲的、不覆盖 tutorial 用到的所有公式。

## Step 1.6: 读已有 tutorial 的公式速查表

Glob `01_Projects/<CODE>_课名/T*.md`。对每个存在的 tutorial:

1. Read 它的 `## 本次公式速查` 段
2. 抽出所有公式 → 加到 Step 1.5 大清单的"**tutorial 实际用到**"列

**意义**：tutorial 用到的公式 = 学生考试要用的公式，蒸馏必须覆盖。Step 1.5 全文扫 + Step 1.6 tutorial 反查，两路保证不漏。

## Step 2: 识别根本起点

**判断标准**：一条公式是"根本起点"当且仅当：

- 不能从其他课内公式推出（必须假设 / 实验定律）
- 整门课**至少 3 个章节**用它派生

**参考表**（按课程类型）：

| 课程类型 | 典型根本起点 |
|---|---|
| 反应工程 | 摩尔平衡、能量平衡、化学计量 |
| 传质 | Fick 第一/第二定律、连续性方程、传质边界条件 |
| 传热 | Fourier 定律、能量平衡、对流换热 |
| 流体力学 | 连续性、动量守恒（Navier-Stokes）、能量守恒 |
| 热力学 | 第一定律、第二定律、相律、状态方程 |
| 单元操作 | 物料平衡、能量平衡、相平衡 |
| 材料 | 晶体结构守恒、热力学相图、扩散方程 |

**典型数量**：3-5 条。少于 3 条说明可能漏抽根本原理；多于 5 条说明把派生公式误当根本。

---

## Step 3: 构建推导树

把所有公式按"原理 → 假设 → 派生"组织成树：

```
根本起点 (§1.X)
    │
    ├─ 假设 A → 派生公式 (§2.X)
    │   │
    │   ├─ 再加假设 B → 应用形式 1 (§3.1)
    │   └─ 再加假设 C → 应用形式 2 (§3.2)
    │
    └─ 假设 D → 派生公式 (§4.X)
```

把树状结构**线性化成 §1 → §N 章节序列**，每章公式带连续编号 (1.1)(1.2)...(N.X)。

**线性化原则**：
- §1 根本起点（守恒方程 / 公理）
- §2-N 派生公式按"距离根本起点的步数"排（先 1 步派生，再 2 步派生）
- 应用层（多反应 / 非等温 / 多相催化 / 非理想反应器）放后面
- 末尾 §N+1 公式索引

---

## Step 5: 符号说明编制

三个表（Roman / Greek / 下标）。要求：

- **每个符号给中英双语**（用户可能要看英文教材 / 考英文卷）
- **多义符号**列出每个含义 + 节号（如 "$a$ 化学计量 §1.3 / 催化剂活性 §9.2 / 外表面积 §10.3"）
- **易混符号**加提醒（如 "$Da$（**不要跟 $D_a$ 混**）"、"$\phi$ vs $\phi_1$ vs $\phi_D$"）

英文术语用 **Fogler / Levenspiel 标准用语**：
- $\eta$ → Effectiveness factor
- $\tau$ → Space time
- $\phi$ → Thiele modulus
- $\phi_D$ → Instantaneous yield
- $\theta_v$ → Fraction of vacant surface sites

## Step 6: 自检 checklist

- [ ] 公式编号 (1.1) → 末尾节，连续无跳号
- [ ] 跨节引用（"代入 (2.5) 得 (3.1)"）— 编号都对得上
- [ ] 符号表所有出现的符号都覆盖
- [ ] 易混符号都标了
- [ ] 文件长度 200-400 行（超过说明没"读薄"，低于说明缺内容）
- [ ] 没有 callout / emoji
- [ ] 公式索引末尾对得上所有 (X.Y)
- [ ] Step 1.5 大清单的所有公式都进了 _principles 或明示"不进"

**编号校验**：`grep -oP '\\tag\{[0-9.]+\}' _principles.md | sort -V` 看序列是否连续。
