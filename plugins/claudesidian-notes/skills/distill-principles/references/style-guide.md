# 教科书风格规则

`_principles.md` 是**教科书风格**，不是 callout 堆砌。下面是从 CME213 v1→v4 摸出来的硬规则。

## 必须遵守

| 规则 | 例子 |
|---|---|
| 公式按 (X.Y) **连续编号到底** | (1.1), (1.2), ..., (11.3) |
| 推导拆**编号步骤** 1-4 | "1. 换元 → 2. 通解 → 3. BC → 4. 整理得" |
| 假设用**表格**列出 | 多个反应器 / 多种条件对照 |
| 关键章节末尾加 `> **常见错**：xxx` 一行 | 普通 blockquote |
| 物理意义 / 极限用**短句**写在公式下方 | "$\phi \to 0 \Rightarrow$ 反应慢扩散快粒内均匀" |
| 反直觉点用 `**...**` 加粗 | "**CSTR (50k) < PFR (150k)**" |

## 严禁

| 禁止 | 原因 |
|---|---|
| `> [!abstract]` `> [!tip]` `> [!warning]` `> [!important]` callout | 用户嫌乱 |
| emoji（⭐ ⚠️ ✓）在正文 | 同上（markdown 表格里少量 OK） |
| "为什么这么做" 长叙述段 | 教科书极简连接词就够 |
| "用法示例 / 这文件给谁看 / 我的疑问" 这种 meta 段 | 浪费篇幅 |
| wiki link 列了名字代替正文展开 | 必须正文有公式 + 解释 |
| ASCII 图 | 用户嫌乱 — 用文字 + 表格代替 |

## Style examples

### Good

```markdown
### §3.1 一级反应

$-r_A = k\,C_{A0}(1-X)$，代入 (2.5)，$C_{A0}$ 消：

$$\tau_{PFR} = \frac{1}{k}\int_0^X \frac{dX}{1-X} = -\frac{1}{k}\ln(1-X) \tag{3.1}$$

> **常见错**：$C_{A0}$ 消基于液相恒容假设；气相变 mol 时不消。
```

### Bad（旧 callout 风格）

```markdown
### §3.1 一级反应

> [!important] ⭐ 关键公式
> 一级反应在 PFR 里的闭式解非常重要！

PFR 设计方程的物理意义是 "...." (一大段叙述)

代入 1 级速率公式 $-r_A = kC_A = kC_{A0}(1-X)$（这里用 $C_{A0}(1-X)$ 是因为液相恒容下 $C_A$ 跟 $X$ 关联，从化学计量的角度看 ...）

$$\tau_{PFR} = -\frac{1}{k}\ln(1-X)$$

> [!tip] 物理意义
> 这个公式说明 ...

> [!warning] ⚠️ 注意
> 容易踩坑的地方 ...
```

## 推导风格

**编号步骤**（不只是段落叙述）。例：

```markdown
**推导 (10.3) → (10.5)**（$\phi_1 = R\sqrt{k/D_e} = 3\phi$）：

1. **换元**：$u = C\,r$，(10.3) 化为 $u'' = (k/D_e)\,u$
2. **通解**：$u = A\sinh(\sqrt{k/D_e}\,r) + B\cosh(\sqrt{k/D_e}\,r)$
3. **边界条件**：$r=0$ 时 $C$ 有限 ⇒ $B=0$；$r=R$ 时 $C = C_{As}$ ⇒ 定 $A$
4. **Effectiveness 定义**：$\eta = \bar r/r_s = (3/R)\cdot D_e(dC/dr)|_R/(k\,C_{As})$，代入步骤 3：

$$\eta = \frac{3}{\phi_1^2}(\phi_1\coth\phi_1 - 1) \tag{10.5}$$
```

## "常见错" blockquote 规则

- 用普通 `> **常见错**：...` 不用 `> [!warning]`
- 一行说清楚 — 不展开
- 放在节末（公式后面），不打断推导
- 不是每节都加 — 只在**真的常错**的章节加

例：

```markdown
> **常见错**：$\varepsilon$ 只对**气相变 mol** 有效。液相恒容 $\varepsilon=0$。
```
