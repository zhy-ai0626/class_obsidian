## §Step 5 — 逐题解答(方案 B 完整规则)

按 `${CLAUDE_PLUGIN_ROOT}/skills/ingest-tutorial/assets/tutorial.md` 结构。**每题一条线性叙事,不要把同一推理拆成"思路+解答+最终答案"三段说**。

**> (原题)** — verbatim,英文给的就英文,数字 / 公式 / 子题编号保持原样

**中文翻译**(默认必带):把题目翻成中文一段。数字 / LaTeX / 子题编号 (a)(b)... 保持原样;题面括号里的参考答案(如 `Ans: 7800 Pa`)也照翻并保留;遇到不确定的术语用"英文(中文)"双语标注。**短的纯英文概念题(< 20 词)可以跳过翻译**,长计算题或表格题必带。

**用到公式**:列出本题用到的 `_principles` 公式编号 (X.Y) — 如 "(3.4) Stefan flow + §2.4 Knudsen 判别"。_principles 缺的公式标 `⚠️ _principles 缺`,后续 Step 7.6 汇总。**不用 `[[wikilink]]` 引概念**(老规范,已废弃)

**解答**(中文,**一气呵成的推理链**):
- **开头一句点明题目本质要做什么**——这取代独立的"思路"段
- **量级估算**:正式算前粗估答案范围(例:"气相 D ~10⁻⁵ m²/s,如果算出 10⁻² 就要查单位")。**作为解答的第一步内嵌**,不另开段
- **逐步推导**:每步一行 motivation + 数学;LaTeX 全程;符号推导先,代数最后;**每一步的"为什么这么做"直接写在该步上方**——不要把 why 全堆到开头
- **对照估算**:答案出来后跟量级估算比,偏差 >1 个数量级要标注
- **结尾用一段 `**最终答案**: ...(带单位)` 标出**——**不再单独开"最终答案"独立小节**(避免同一结论写两次)

**English Concise Answer**(默认必带):100–200 词的英文段落式答案,**可直接抄到考卷上**。要求:
- 完整句子,**不是 bullet points**(教授要看连贯英文论述)
- 含关键公式 + 关键数字 + 最终结论
- **不复制中文解答的所有细节**——只保留答题必要的步骤和结论(若中文解答 500 字,这里 150 字)
- 计算题:列关键公式 → 代入数 → 最终数值带单位
- 概念题:2–4 个完整段落覆盖所有要点(分类 / 定义 / 例子 / 对比 / 工程意义按需)

**易错**:预测学生常错的点(`> [!warning]` 块,2–5 条 bullet)

**变式**(可选,不强制):1–2 个 "what if" 扩展

### 结构清晰的反例和正例

❌ 旧结构(逻辑断裂,同结论说 3 次):
```
思路: 我打算用 Bragg 公式。
解答: 套 Bragg 公式 → a = 0.317 nm
最终答案: a = 0.317 nm  ← 重复
```

✅ 新结构(一条线):
```
解答: 题目本质是从 XRD 峰位反求晶格常数。先估算量级(金属 a ~0.3 nm)。
第一峰是 BCC 的 {110}(选择规则要求 h+k+l 偶,所以最小 h²+k²+l²=2)。
用 Bragg λ = 2d sinθ → d = 0.225 nm → a = d√2 = 0.318 nm。
跟估算 0.3 nm 一致。
**最终答案**: a ≈ 0.317 nm
```
